# 📊 Mutual Fund Analytics — Capstone Project
** | END TO END Data Analyst project | 2026**

Tools: Python • Pandas • SQL • Power BI

## 🎯 Project Overview
Built an end-to-end analytics solution for 40+ Indian mutual-fund schemes, covering data ingestion and cleaning, SQL analysis, NAV/AUM analysis, SIP and transaction trends, financial metrics, and an interactive Power BI dashboard.
